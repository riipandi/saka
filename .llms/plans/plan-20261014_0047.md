## Current state

Every claim below was verified against the tree on 2026-10-14.

## Decisions

- **D1 (2026-10-14, owner) — the worker's dead-proxy hang is fixed with a
  mutable current-engine indirection plus bounded Comlink calls.**
  `withCookies` routes every engine call through a reference the error
  listener can re-point, and each call is bounded (a liveness race or
  timeout) so a dead worker rejects instead of hanging; the fallback
  engine takes over mid-boot. Rejected: the current
  swap-for-future-callers shape (in-flight calls hang forever — the
  reported defect); abandoning the worker (loses the custody
  architecture plan-20261009_0025 established).
- **D2 (2026-10-14, owner) — the catalog-drift remedy is the startup
  check**: `serve` verifies the administrator role's junction against
  the catalog at boot and logs a loud warning naming the repair command
  when it lags. Nothing writes to the database on the serve path.
  Rejected: the self-healing seeder at boot (a serve that writes is a
  surprise), the documentation-only rule (the silent failure remains).
- **D3 (2026-10-14, owner) — `AssetsURL` joins the public scope**, the
  publisher test pinning it, and the comment stands corrected by the
  code. Rejected: correcting the comment to "administrative" (a
  split-assets deployment would still build on an empty public value).
- **D4 (2026-10-14) — the seed-test totals derive from the seeder
  registry**: the tests compute the expected created/skipped totals from
  what the command will run, keeping the status-line shape assertions.
  Rejected: keeping the hand-bumped counters (the next seed item goes
  red again).
- **D5 (2026-10-14) — the debug E2E run boots its own compiler**: the
  ladder run's `webServer` starts the Vite dev compiler alongside the
  debug binary, and the E2E servers move off :3000 to a dedicated port
  so a lingering `saka serve` cannot serve the wrong build.
  Rejected: embedding the release SPA assets into the debug binary
  (blurs the build boundary — the dev page is the debug build's
  contract); leaving the two-tag manual split (one invocation still
  cannot prove both suites).
- **D6 (2026-10-14) — a parity guard pins the Dockerfile's typecheck
  chain to the vite task** so the six-command chain and the
  `vite.config.ts` task cannot drift silently; the `vp run` workaround
  itself stays until a fixed vp ships (the upstream report is the
  owner's action). Rejected: restoring `vp run` in the Dockerfile now
  (the Linux-container crash returns).
- **D7 (2026-10-14, owner) — the flat `.llms/archive/`.** A single
  archive directory, no subfolders; files move under their existing
  names. The handover history: keep the five newest handovers in
  `.llms/handover/`, move the other 62 to
  `.llms/archive/handover-<stamp>.md`. The plan history: keep the five

  `.llms/archive/plan-<stamp>.md`; the two live contracts

  the retained five. The index's Handovers and Plans sections point at

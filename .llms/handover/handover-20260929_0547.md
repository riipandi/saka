### Slice 7 shape (the deltas vs the 09-28 handover)

- **Device flow** (`modules/federation/oidc`): `deviceStore` implements
  `goidc.DeviceAuthManager` over `oauth_sessions` pointer rows (kinds `device`, `devicecode`,
  `usercode`); `WithDeviceGrant` + a `devicePolicy` that reuses `completeAuthentication`, so the
  SPA interaction flow approves device sessions exactly like authorize ones.
- **Critical library discovery**: go-oidc v0.25.0 has **no public setters** for device endpoints.
  The fix was `provider.WithPathPrefix("/oidc")` with every protocol endpoint constant as a bare
  name (`/authorize`, `/device_authorization`, …); chi mounts `protocolPrefix+endpoint`, policy
  path checks include the prefix. Do not "restore" absolute endpoint paths — that was the bug.
- **Device login** (`modules/devicelogin`, new module): REST create + long-poll exchange
  (`/api/device-login/requests`, 25s window, interval 3s, pairing cookie), RPC inspect/decide
  (`saka.authn.v1.DeviceApprovalService/Inspect|Decide`, guard `Session`, impersonated callers
  refused). Migration `00012` is an **ALTER** of the table from `00002`, not a create.
- **Audit**: `oidc_device_authorized`, `device_login_approved`, `device_login_denied`.

## Known traps hit this session (beyond the 09-28 handover)

1. `go-sqlbuilder` `Set()` called twice **replaces** the first clause — one `Set` with all
   assignments. `sb.Var()` nested inside `Assign`/`Equal` inlines a literal `"$3"` string —
   pass values directly.
2. Test timestamps must respect check constraints: an "expired row" fixture has to move
   `created_at` backward too, not just `expires_at`.
3. `goose` skips `00000_*.sql` silently; version-assertion tests derive totals from
   `database.EmbeddedMigrations()` (see `cmd/migration_test.go`).

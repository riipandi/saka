## Decisions this session settled

- **The administrative doors ride `Admin`, not `Permission(user:*:*)`.** The repo
  convention for over-a-named-account procedures is the administrator role
  (`UserService` CRUD, `MultifactorService/AdminDisableMfa`); `Permission()` had no
  other user in the rules table. The user corrected this after reviewing the guard
  split.
- **The Pocket ID user-passkey Yaak mirrors repoint, not alias.** The collection's
  two `(unimplemented)` `UserService` requests call the shipped
  `WebAuthnService` admin doors now — no duplicate RPC surface. The three admin
  requests live in the Yaak **Users** folder as operator actions; the **Passkeys**
  folder carries the holder surface alone.
- **The two account reads.** `signin.FindAccountByID` inner-joins the password
  table (the stranding question: "is there a way back in");
  `FindAccountByIDAny` left-joins it (the resolution question: "is there an
  account"). The passkey surfaces resolve through the left join — the bug the
  ladder exposed was a passwordless account unable to enroll its only credential.

## Running the E2E again (the recipe that works)

1. Disposable config: copy `app.config.json` to e.g. `/tmp/e2e.config.json` with
   `rate_limit.auth_limit` raised (the default 10 trips inside one ladder run) and
   `rate_limit.limit` raised to match.
2. `task db:reset -- --force --up --seed`, **then start the
   server after the reset** — the JWKS cache in a server that predates the reset
   mints tokens against dead keys and every bearer call answers 401.
3. `CONFIG_FILE=/tmp/e2e.config.json ./build/release/tango --env-file=.env.local serve`
   (build first: `go build -o build/release/tango ./cmd`).
4. `E2E_IDENTITY=admin E2E_PASSWORD='<seed admin password>' go run ./tools/e2e-passkey`
   — the seeded accounts it creates (`sophie`, `vittoria`, `silas`) are the
   caller's to clean up; the run leaves them.
5. TOTP in the driver walks a shared stepping clock: a code is single-use per
   30-second step, and the verify consumes a step **before** the dead-bridge state
   is judged — a live code burned on a dead bridge starves the next honest
   completion into the refusal window. Do not "fix" the driver's `000000` probes.

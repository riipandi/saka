## Durable decisions (why it is built this way)

- **slog is the only frontend** to LogLayer (via `sloghandler`); LogLayer API never exposed. Errors are fields-as-text under `err`, never raw error values.
- **Async logging is zero-drop by user requirement** ("tanpa trade-off kehilangan log"): blocking backpressure turns overload into latency, never loss. Only `kill -9` between enqueue and drain can lose queue contents. User explicitly rejected drop-on-full and bufio-only alternatives.
- **No DX regression on console**: `pretty` stays default; echo sink carries only warn+.
- **`source` is debug-only** (user: sensitive).
- SIMD (`simd/archsimd`) is the wrong tool for I/O-bound bottlenecks — do not revisit for logging.
- Process lesson: parallel `edit_file` calls to the *same file* overwrite each other (last-write-wins) — edit sequentially.

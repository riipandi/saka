## Gotchas learned this session (durable)

- `sqlbuilder.Flatten` unpacks `uuid.UUID` (an array type) into its bytes — build `[]any` of
  UUIDs directly for `sb.In(...)`.
- `rs/cors` v1.11.1 is **case-sensitive** on preflight header names (it lowercases the configured
  list, compares raw request values) and requires the `Access-Control-Request-Headers` list
  **lexicographically sorted**; preflights echo `Access-Control-Request-Method/-Headers` rather
  than listing the allowed sets, and `Access-Control-Expose-Headers` only appears on actual
  (non-preflight) responses. Tests must assert through that shape.
- Never rewrite `public/config.schema.json` with `json.dump` (em-dashes become `\u2014` escapes
  and the diff explodes); insert entries textually.
- Proto enum wire names (`SORT_ORDER_DESC`) leak into JSON — when the user wants friendly wire
  values, use a validated string field, not an enum.
- `usergroup` group IDs travel as `ugrp_` TypeIDs; convert with `usergroup.UUIDFromWire` /
  `usergroup.FormatID`. `user.UserView.ID` is the wire string; `user.UUIDFromWire` converts.
- A test-local variable named `user` shadows the `user` package — rename the variable.
- `signup` display-name composition requires non-empty first/last names (`users_display_name_check`
  rejects the empty composition); test fixtures must pass names.

## Contracts the screens encode

- **Show-once** — the OIDC secret and the SCIM token both answer once at
  creation through `components/dialogs/-show-once-secret-dialog.tsx`; the
  stored value is a SHA-256/prefix pair the UI never sees again.
- **Step-up** — `UnlinkConnection` rides `useStepUp()` with a promise
  client built over `useTransport()`; the proof is spent exactly once via
  Connect call hints, a dismissal is swallowed (`StepUpCancelled`).
- **Group restriction** — effective restriction is the flag *or* a
  non-empty allowed-groups roll (`protocol_policy.go`); an empty roll
  under a standing flag admits nobody, and the GroupsCard says so.
- **Custom-attribute semantics** — the update's unset optional fields keep
  the stored value; an empty custom-attribute list clears the set; the
  mapping merges per claim key.
- **Scope wording** — `offline_access` renders as "persistent access",
  `login_hint` as "prefills the sign-in form"; other scopes are plain
  chips.

## Trap notes for the next wave (Wave 5)

- **Catalog pins** — `cmd/initialize_test.go` and
  `internal/database/seeders/usergroup_factory_test.go` pin counts; a new
  catalog resource moves three numbers in one commit.
- **Invalidate keys** — Connect-Query invalidation must use
  `createConnectQueryKey({schema, cardinality: 'finite'})`; a raw string
  key matches nothing and the list stays stale.
- **Dialog form seeding** — seed a dialog's fields from a
  `useEffect([open, subject])`, not from `useState` initializers plus a
  key remount: the remount does not fire when the seed arrives via an
  async query in the browser test mounts.
- **oxlint `no-unsafe-type-assertion`** — narrowing casts fail lint even
  when `tsc` passes; use type guards (`isRecord`), and a `press()`
  helper with an `instanceof` check for element clicks.
- **Pipelines hide failures** — `go test | head` and `vp check | tail -1`
  cut the failure lines; grep for the failure markers or read exit codes.

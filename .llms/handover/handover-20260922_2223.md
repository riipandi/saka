## Gotchas the next agent must know

- **Lint with `task lint` (or `golangci-lint run -c .config/golangci.yml ./...`), never
  bare `golangci-lint run`** — the config enables govet `shadow` and gosec; bare runs
  hide them and gave this session a false "0 issues".
- govet `shadow` flags any inner `err :=` when an outer `err` exists and is used later;
  fix by `err = ...` or renaming. gosec G602 only accepts an `if i < len(s)` guard
  lexically wrapping the index.
- `cmd/migrate_debug_test.go` and `cmd/migrate_seed_test.go` are `//go:build debug` —
  run `go test -tags debug ./cmd/` to compile them; shared test helpers must live in an
  untagged `_test.go` file in the same package.
- The OTel `otel/log` pin (v0.19.0, three modules) is fragile after any `go get` —
  re-check and re-pin per AGENTS.md.
- Never commit/push on own initiative; never `git add -A`; recommend a commit title and
  let the user commit.

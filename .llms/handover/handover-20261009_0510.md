## The two dev-mode root causes (f887a1d7) — why "first load unstyled"

1. The Go debug shell loaded the StyleX dev runtime via `/virtual:stylex.js`
   — the unplugin's raw middleware path, served WITHOUT a Vite transform, so
   `import.meta.hot` was undefined and the sheet never refreshed past the
   first fetch. `web/static_debug.go` now mirrors `transformIndexHtml`: a
   render-blocking `<link rel="stylesheet" href="/virtual:stylex.css">` plus
   `<script type="module" src="/@id/virtual:stylex:runtime">`.
2. `auth-cookies.ts` imported the `#/libraries/cookies` barrel, which
   re-exports React provider/hook code — the auth worker's import chain
   evaluated `cookies-context.ts` in the worker realm, dev's react-refresh
   wrapper threw `$RefreshSig$ is not defined` there, and the router's
   `beforeLoad` hung on the dead proxy (blank page, zero console errors).
   The barrel→concrete-module import is the standing rule: **the worker's
   import chain must not evaluate React surface code** (recorded in
   `.llms/architecture.md`'s auth-worker record).

Release mode was never affected by either (build-time CSS embed, no
react-refresh in the worker build pipeline).

## Remember-me lifetimes (d7fa913f)

The flag traveled end-to-end but minted the SAME window both ways — the
2026-10-01 settings-catalog migration had collapsed the original short/long
TTLs into one shared `session.max_lifetime`, contradicting the proto
contract text. The owner picked "restore the split": the new catalog key
`session.lifetime` (non-remembered, default 12 h, capped by the remembered
bound) beside `session.max_lifetime` (remembered, default 7 days);
`signin.SessionLifetime(ctx, remember)` branches, `IssueSession` and the
session refresh rotation both consume the remember-aware value. The access
TTL deliberately does not follow remember.

## The request-log quiet filter (d82989cb)

`framework/middleware/logger.go` `Logger(log, quietPrefixes ...string)`:
prefix match on the URL path, silent below the error level (successes AND
4xx — a devtools-probe 404 is the browser's normal state), 5xx never quiet.
The list lives in `internal/transport/router/http.go`
(`quietRequestPrefixes`) — favicons, `/.well-known/appspecific/`, and the
dev compiler's graph (`/src/`, `/@fs/`, `/@id/`, `/@vite/`,
`/@react-refresh`, `/virtual:`, `/__tsd/`, `/node_modules/`).

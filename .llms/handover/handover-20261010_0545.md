# Handover — the account wave (plan-20261010_0054)

## What shipped

All nine phases of the plan executed and committed. The account is real
data end to end:

- **Phase 1** (`9ac77f15`) — `hooks/use-pagination.ts` (`usePaginatedList`,
  search-param page/sort, `ListMetadata` decode, `LIST_DEFAULT_LIMIT`/
  `LIST_MAX_LIMIT`) and the Connect-code mapping in `getErrorMessage`
  (`libraries/guard/auth-utils.ts`).
- **Phase 2** (`834ee1c3`) — `users.self_delete_enabled`,
  `users.change_email_enabled`, `users.change_username_enabled` became
  public catalog items (`modules/appconfig/settings.go`), catalog test
  pins twelve public items.
- **Phase 3** (`ab26ede4`) — the settings page on real data: names/locale/
  timezone save (store patch from the response), the raw-body picture
  upload/reset with a Blobatar fallback, the danger zone gated by the
  public toggle. Probe-verified live.
- **Phase 4** (`3ebb0649` + corrections `5a6e662d`, `f4f4d95a`, `b1501fa2`,
  `6acc7199`) — the session center: uilibs Item rows, the wire's `current`
  flag, sign-out-others and sign-out-all behind their own confirmations;
  the per-row revoke deliberately deferred to Wave 2 (step-up guard on
  `RevokeSession`). Route-file pattern settled: thin `RouteComponent`
  wrapper in the route file, implementation in dash-prefixed siblings.
- **Phase 5** (`911105b8`) — the email identity page and the no-session
  `/verify-email?code=` door. The mailed token is a 12-character
  unambiguous-alphabet code typed into an OTP field; the change flow is
  `RequestEmailChange` → `ConfirmEmailChange` gated by the public toggle.
  Probe-verified against the live backend (a seeded token verified an
  account; a replay answered "invalid or expired").
- **Phase 6** (`88977955`) — the own-audit page: display-only records as
  sentences (event, outcome badge, delegated actor), sort whitelist riding
  the route search, newest-first by sending no sort fields.
- **Phase 7** (`ecb772a3`) — shell residue: the root is a pure redirect
  (owner decision, no landing page), the sidebar reads "Saka" with an
  Account section, the overview's template residue is gone. Icons:
  `@keyline-icons/react` stroke for idle items, two-tone for the selected
  one (`02a4aa33`).
- **Phase 8** (`cdfa006e`) — the E2E files
  `packages/e2e-tests/workflow/account-{profile,sessions,email,audit}.test.ts`
  over `helpers.ts`; 19/19 green twice back to back. Bugs the suite shook
  out and fixed in the same commit: the settings draft's refetch race, the
  OTP fields' numeric-only validation (`validationType: 'alphanumeric'`),
  and the doubled code in six plain-text email templates — root cause was
  react-email's `CodeInline` rendering twice; the templates now use the
  single-render `Code` in `packages/email/components.tsx`.
- **Phase 9** (this commit) — the docs rollup and the validation matrix.

  500 for any account holding one. Live now means unexpired in both the lock
  read and the write; the regression test pins the predicate.

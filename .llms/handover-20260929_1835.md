## Remaining work

1. **Wire `/oidc/end-session`** — the endpoint is mounted but answers
   `invalid_request` for every request: `provider.WithLogout` runs without
   `WithLogoutPolicies`, and go-oidc refuses to open a logout session
   without a policy. Implement the policy (setup + logout callback that
   revokes the account's grants and pointers for the client, ignore an
   unregistered `post_logout_redirect_uri`) and add integration tests.
   The reference row and its paragraph in `.llms/endpoint-reference.md`
   already describe this as the planned contract.
2. **Decide the token-type discriminator** — the reference once claimed ID
   tokens carry `tango:token_type = id-token`; no token path writes it and
   the library's logout verifies only signature and audience. Decide
   whether the claim should exist (a product/protocol decision — ask)
   before touching tokens; it is already a reserved custom-claim key.
3. **Land the Yaak mirror** — six request descriptions were updated in the
   Yaak workspace (`yaak request update`, CLI 2026.8.1) for the
   reserved-claim refusals, the device-login 429 cap, and the fail-closed
   `ListMyClients` catalogue. `api/specs/` is written by the Yaak app's
   git sync, not the CLI; run that sync and commit the mirror.
4. **Housekeeping** — `.llms/plan-20260929_1722.md` tracks phase status in
   its frontmatter; keep the `updated` timestamp moving with each phase.
   The parity baseline is Pocket ID v2.16.0 (the v2.15/v2.16 deltas do not
   change the compared endpoint shapes).

## The two defects the release E2E found

1. **`admin/users.tsx` shadowed `admin/users/$id.tsx`.** In TanStack's file
   conventions a page file beside a same-named directory is that directory's
   layout; without an `<Outlet/>` the child never rendered — the detail page
   had never worked through the router (the browser tests mounted the view
   directly, so phases 2–6 stayed green). The list moved to
   `admin/users/index.tsx`. The trap is recorded in `.llms/rules.md` (the
   admin-console bullet) — the same shadowing is safe wherever a page has no
   children (`groups.tsx`, `blocklist.tsx`, …).
2. **`//go:embed output` excluded the code-split chunks.** Go's embed skips
   files whose names begin with `_` or `.`, and the router's chunks are named
   after their route files (`$id.tsx` → `_id-….js`) — the release binary
   answered every code-split page's chunk with `index.html`. The pattern is
   `all:output` now (`web/binding.go`), trap recorded in the same bullet.
   **Every future release build needs the rebuilt binary; the running dev
   server never had this bug.**

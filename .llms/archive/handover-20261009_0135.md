## Harness lessons worth keeping

- The Playwright webServer now runs from the **repository root** (the
  binary requires `app.config.json` and `.env.local` beside it — from
  the package directory it never booted) and **rebuilds the SPA first**:
  the binary embeds `web/output` as it stands, so a stale embed silently
  serves the previous bundle. This cost a debugging detour in phase 6.

  passkey ladder needs its devtool pages, so run it with
  `E2E_BUILD_TAG=debug`. Both verified green.

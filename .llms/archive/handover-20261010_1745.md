# Handover — the frontend observability wave (plan-20261010_0925)

## What shipped

- **The public telemetry fact** (phase 1, `44a037b7`): `otel.browser.endpoint` +
  `otel.browser.ratio` in the public scope of `GET /api/configuration`
  (`internal/config/types.go` `OTEL.Browser`, `publish.go` `PublishedOTELBrowsing`
  in both scopes, `validate.go` holding the endpoint to an absolute URL and the
  ratio to 0–1, the sample config's `OTEL_BROWSER_ENDPOINT`). An empty endpoint
  omits the whole `otel` section from the public body. The dev collector answers
  the CORS preflight (`container/otel-collector.yaml`, `http://localhost:3000`).
  The webapp's config schema parses the section; `docs/observability.md` and
  `docs/configuration.md` carry the operator side.
- **The web tracer foundation** (phase 2, `c09f6226`): `libraries/telemetry/` —
  `telemetry.ts` (the resource `saka-web` + `app.mode` + the build's version, the
  `ParentBased(TraceIDRatioBased)` sampler, a `BatchSpanProcessor` into the
  OTLP/HTTP exporter, the W3C propagator, idempotent init, `shutdownTelemetry`),
  `-redaction.ts` (one exporter wrapper: query strings stripped off
  `url.full`/`url.original`/`url.path`, `url.query`/`url.fragment` dropped, spans
  aimed at the telemetry endpoint itself or any third-party origin dropped
  wholesale), and `telemetry-provider.tsx` (mounted in `__root.tsx`; idle-tick
  init after the document answers; inert when off).
- **Client spans at the seam** (phase 3, `4751143a`): `authFetch` opens one HTTP
  client span per real round trip (`HTTP <method>`, the semconv attributes, the
  status code attribute on the answer, `Error` on non-2xx and on network failure
  with the exception recorded) and injects `traceparent` from the span's own
  context. A 401 replay is its own span; the refresh behind it is the engine's.
- **Navigation spans** (phase 4, `d2fa810a`): `navigation.ts` wired in `main.tsx`
  — opened at `onBeforeLoad` with the pathname, renamed to the resolved route id,
  ended at `onResolved`; a redirect-superseded navigation ends silently, an
  errored match ends the span as an error.
- **The worker joins the trace** (phase 4, same commit): the facade
  (`auth-worker-client.ts`) spans each user-caused operation (`auth login`,
  `auth continue-sign-in`, `auth refresh`, `auth maybe-refresh`, `auth restore`,
  `auth session`, `auth logout`) and hands the `traceparent` through the engine
  call, which rides it as **Connect call headers** (`auth-engine.ts` —
  `callHints`/`withHints`), not mutable transport state a concurrent call could
  read. `accessToken`/`authorization` stay uninstrumented. The worker realm never
  imports the SDK.

## The decisions worth remembering (plan D1–D8)

- **D1** — the browser's collector is a public configuration field; the proxy
  and build-time shapes were rejected with reasons (architecture.md's record).
- **D2** — the collector answers the CORS check; only the dev compose config
  ships a value, production fronts its own collector.
- **D3** — one span per request at the one seam; the monkey-patching
  instrumentations stay out.
- **D4** — the worker joins through the facade; Connect call headers, not
  transport state; plumbing uninstrumented.
- **D5** — parent-based ratio; zero ratio = everything (the loud default —
  an operator who named a collector wanted spans).
- **D6** — redaction written once at the export path.
- **D7** — metrics and logs stay backend-only until a named need.
- **D8** — lazy init after first paint; the web client names itself with code
  constants because the process's `service_name`/`environment` are
  administrator-scope.

## What the next wave inherits

- `sendWithSeamSpan` and `spanOperation` are the two span helpers any future
  instrumentation rides — new request paths go through `authFetch` and get spans
  for free; new operation wrappers call `spanOperation`.
- `otel.browser` is a plain publisher field — an admin-screen editor for it is
  Wave 5's settings work, nothing here blocks it.
- The collector round trip is owner-runnable: `docker compose -f
  container/compose-sre.yaml up -d otelcol openobserve`, set
  `otel.browser.endpoint` to `http://localhost:4318` in `.env.local`, and the
  `saka-web` traces land beside the Go process's in OpenObserve.

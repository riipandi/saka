## Phase 3 — residue cleanup (aggressive, owner-approved)

Dead tables (zero Go references; goidc stores auth codes and device codes as
`oauth2_sessions` rows of kind `authcode` / `devicecode`, proven in
`modules/federation/oidc/protocol_storage.go`):

- drop `public.oidc_authorization_codes` and `public.oidc_device_codes` with
  their indexes and FK constraints, from the federation file.

Uncalled SQL functions (no Go caller; `fn_check_rate_limit` is the only one
the code invokes, in `internal/transport/middleware/ratelimit_database.go`):

- drop `fn_get_rate_limit_info`, `fn_cleanup_rate_limits`,
  `fn_reset_rate_limit`, `fn_get_rate_limit_stats` from the rate-limits file.

Indexes with no query behind them (each verified by grep over the repos
before the drop lands; anything the sweep or a sort does read gets kept):

- `idx_rate_limits_key` — the primary key covers it.
- `idx_webhook_endpoints_name` — `UNIQUE (name)` covers it.
- `idx_webhook_endpoints_headers_gin` — headers are never filtered.
- `idx_sessions_user_id` — leading column of `idx_sessions_user_id_expires_at`.
- `idx_sessions_ip_address` — no query filters by IP.
- `idx_auth_tokens_purpose` — lookups go by `token_hash` (UNIQUE) or
  `(user_id, purpose)`; confirm with EXPLAIN before dropping.
- `idx_api_keys_last_used_at`, `idx_api_keys_updated_at` — no reader today;
  confirm against `modules/apikey/repository.go` sort columns first.

Kept by decision: `users.metadata` + `idx_users_metadata_gin` (owner), the
`hstore` extension (created in the untouchable `00001`), `get_database_sizes`

## Phase 4b — `users.timezone` and `users.locale` move into `users.metadata` (owner correction)

The columns are dropped from `public.users`; the JSONB document in
`users.metadata` becomes their home. The proto wire shape does not change —
`timezone` stays a required-presenting field defaulting to `UTC`, `locale`
stays optional — only the storage moves.

- DDL (`00002`): drop the `timezone` and `locale` columns and the
  `chk_users_timezone` check. `metadata` and its GIN index stay.
- `modules/identity/user/schema.go`: `UserSchema` loses `Locale` and
  `Timezone`, gains `Metadata` (the JSONB column, marshalled in Go as a
  document the package owns).
- `modules/identity/user/repository.go`: the scan list, the update assign,
  and the insert columns stop naming the two columns; the metadata document
  travels as one value. Reading runs through one helper per key —
  `metadataTimezone` (absent or malformed → `DefaultTimezone`) and
  `metadataLocale` (absent or malformed → nil) — so no call site pokes the
  JSON itself.
- `modules/identity/user/service.go`: `CreateUser` / `UpdateUser` /
  `UpdateCurrentUser` write the two keys into the document;
  `normalizeTimezone` keeps its rule (empty → `UTC`, unknown → refuse); an
  empty locale clears the key. The views read the keys back through the
  helpers, so the wire answers exactly as before.
- `modules/identity/user/handler_rpc.go`: no change — the mapping targets
  the service params, not the columns.
- `database/seeders/user_factory.go` and `cmd/initialize.go`: drop the
  `Timezone: user.DefaultTimezone` field — an absent key already means
  `UTC`, and seeded accounts need no metadata row.
- Tests: the timezone and locale service tests keep their assertions (the
  view is the contract); fixtures that poked columns directly follow the
  new write path.

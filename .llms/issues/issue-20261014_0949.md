# Residues from the archived `partial` handovers (Sep 22 – Sep 30)

The fifteen archived handovers carrying `status: partial` (2026-09-22 →
2026-09-30) and plan-20261012_0155's `partially-done` phase 5 were
reconciled against the tree on 2026-10-14. What landed since — the health
checks, the mailer and its durable-queue email pass, the per-package
metrics, notification, webhooks, impersonation, password recovery, the
session-rotation reuse guard, the delete-hash guards, the api-key renew
guard, the storage hash-reuse guard, the algorithm-pinned verifier
(`pkg/jwtutils/access.go`), the lifecycle shutdowns, the rate-limit mount
(test-pinned), the GeoIP resolution, the consent screen — is recorded
here only as settled. These are the residues.

- status: open
  area: cli / appkey
  summary: `key:rotate` prints `not yet implemented` and exits
    (`cmd/appkey.go:177`) — the stale-encryption-key rotation the mailer
    handover promised never landed; `key:generate` beside it works.
  trigger: The first deployment that must rotate an encryption key
    (compromised key material, or a cipher migration).

- status: open
  area: backend/config + queue
  summary: The `queue.release_after` invariant — "must stay above the
    longest queue Timeout" (`internal/config/defaults.go:159`) — is
    enforced nowhere: `internal/config/validate.go:267` checks only
    `> 0`. The default rose to one hour (above the 30-minute chunk-upload
    timeout), so the shipped shape is safe; an operator's small
    `release_after` still lets a second worker re-claim a task the first
    is still running. (The defect came from handover-20260923_0415
    defect 5; the default half landed, the cross-check did not.)
  trigger: Any queue task configured with a `timeout` above the
    operator's `release_after`, or the next touch of
    `internal/config/validate.go`'s queue block — a `ReleaseAfter >
    max(task timeouts)` check closes it.

- status: considering (trigger: a deployment switches storage drivers)
  area: cli / storage
  summary: The `storage:migrate` command — moving stored objects between
    the local and S3 drivers — was proposed in the 2026-09-26 session and
    never started; `cmd/manage.go` carries only `admin:reset-password`.
  trigger: An existing deployment changing `storage.driver`.

- status: considering (owner-deferred 2026-09-27)
  area: backend/transport
  summary: The `rs/cors` replacement was explicitly deferred as optional
    when the CORS defaults were reworked (handover-20260927_1645); the
    library is still the router's CORS layer (`go.mod:42`).
  trigger: A CORS requirement `rs/cors` cannot express (per-route
    policies, header propagation into the response pipeline).
